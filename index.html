这个项目是什么 ​

把《塞尔达传说 时之笛》N64 原版 ROM 里森林神殿的幻影加农 boss 房(moribossroom)移植到 Nintendo DS: 房间几何、纹理、碰撞、透视相机与 Link 的可行走,全部跑在 DS 那套固定函数硬件管线的约束下 (顶点色 + CI4/CI8 纹理、无浮点、无 per-poly z-write、顶点吞吐有硬上限)。

批准的终点是裁剪版:静态场景 + 本体静态网格 + Link 可行走。不做:跨房间 exit、水/WaterBox、 boss AI 与战斗、bgCam 分区变相机、N64 原版参考截图管线。

本体身份钉死过一条误判:object_sst 是 Bongo Bongo(影之神殿),幻影加农是 actor type 0x52 → object_gnd,Standard 骨架而不是 Flex ⇒ 运行时正向运动学(FK)不在本场景的依赖里。

复现这里看到的一切 ​

make -s                                                              # 角色 ROM(锚定 8a546db4)
make -s SCENE=moribossroom WALK=1 BOSS=1 STARTX=15 STARTZ=-2900 \
     CAMYAW=0.0 CAMPITCH=-5.0                                        # 验收 ROM(锚定 dd9bfa50)
python3 tools/acceptance_gate.py                                     # 32 项读数,不重编
python3 tools/acceptance_gate.py --rebuild                           # 65 项,含 33 台逐位复现
python3 tools/gen_site.py                                            # 再生本站的四页
python3 tools/gen_site.py --check-dist                               # 体检建好的画廊(人眼门判的是它)
npm --prefix web/site run docs:dev                                   # 起本站(http://localhost:5173)

站内数字与图片均由 tools/gen_site.py 从 docs/scene-port.md 与 evidence/ 生成，不在站里抄第二份。
